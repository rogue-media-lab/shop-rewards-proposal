## Proposal Highlights

### What Makes This Unique
✅ **Multi-franchise platform** (supports BOTH Speedee and Grease Monkey in one codebase)
✅ **70-90% cheaper** than agency builds ($12.5k vs. $150k-500k)
✅ **Barcode POS Bridge** (franchise-safe, no API integration)
✅ **Dual Loyalty System** (Points + Perks)
✅ **Services Display** (Valvoline-style transparency)
✅ **Location-based architecture** (shop selection, QR codes, owner dashboard for multi-shop management)
✅ **Fixed-price contract** (no surprise overages)
✅ **Source code ownership** (asset even if pilot fails)

### What's Included in MVP
✅ Customer PWA (phone signup with shop selection, QR code support, coupon wallet, rewards tracking)
✅ Manager dashboard (Flash Sale button, customer lookup, PO transaction workflow - shop-scoped)
✅ Owner dashboard (multi-shop aggregate view, performance comparison across franchises)
✅ Push notifications (real-time Flash Sale alerts, shop-specific)
✅ Dynamic branding (Speedee vs Grease Monkey theming)
✅ Legal compliance (TCPA, GDPR, Privacy Policy, Terms of Service)
✅ Training materials (video, quick reference guide, FAQ)

### Success Criteria
✅ 10%+ increase in daily car count
✅ 15%+ Flash Sale redemption rate
✅ 100+ customers per shop
✅ Positive manager feedback
✅ Positive ROI within 30 days
✅ Multi-franchise validation (pilot includes shops from BOTH Speedee AND Grease Monkey to prove platform works for both brands)
